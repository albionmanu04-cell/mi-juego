FORJA ETERNA · ACTIVAR CUENTAS Y GUARDADO ONLINE
================================================

1. Entrá a tu proyecto de Supabase.
2. Abrí Authentication > Sign In / Providers > Email.
3. Activá Email y permití nuevos registros.
4. Para probar inmediatamente, podés desactivar temporalmente "Confirm email".
   Si lo dejás activo, cada jugador deberá confirmar el correo antes de ingresar.
5. Abrí SQL Editor > New query.
6. Copiá todo el contenido de "supabase-cloud-save.sql" y presioná Run.
7. Copiá todo el contenido de "supabase-comercio-jugadores.sql" y presioná Run.
8. Subí esta versión del juego a GitHub/Vercel.

COMERCIO SEGURO V2
------------------
- La Lonja permanece cerrada si el servidor no responde con el protocolo V2.
- El SQL anterior queda sin permisos y sus publicaciones se conservan sólo
  como historial; no se importan automáticamente al mercado nuevo.
- Cada cuenta recibe una billetera online inicial de 30 Sellos.
- Comprar, acreditar al vendedor y transferir la pieza ocurre en una sola
  transacción. Las ventas ya no se cobran manualmente.
- El navegador no puede escribir directamente billeteras, piezas,
  publicaciones ni el libro contable.
- Los objetos remotos se reducen a campos conocidos y todas las imágenes
  deben ser rutas locales dentro de assets/images/.

LÍMITE DEL MODELO ACTUAL
------------------------
El combate y el botín siguen ejecutándose en el navegador. Por eso el servidor
puede garantizar que una publicación no se duplique, que una compra tenga saldo
y que los datos compartidos no ejecuten HTML, pero no puede demostrar que una
pieza nueva fue obtenida legítimamente jugando. Para protección anti-cheat total,
la generación de botín también deberá trasladarse a una función del servidor.

SEGURIDAD
---------
- Cada cuenta solo puede leer o modificar su propia partida.
- Las contraseñas son administradas por Supabase y nunca se guardan dentro del juego.
- El juego conserva una copia local inmediata y otra online cada 12 minutos.
- Los personajes locales existentes se vinculan a la primera cuenta utilizada.

PRUEBA RECOMENDADA
------------------
1. Creá una cuenta.
2. Creá o abrí un personaje y jugá unos minutos.
3. Esperá a ver "Nube actualizada" o cambiá de pestaña.
4. Abrí el juego en una ventana privada e iniciá sesión con la misma cuenta.
5. Tus personajes deberían recuperarse automáticamente.

REINICIO GLOBAL DE TEMPORADA
----------------------------
La versión actual usa el espacio local "temporada-2", por lo que ignora todos los
personajes locales creados antes de esta actualización.

Para eliminar también el progreso online y el ranking anterior, ejecutá una sola vez
el archivo "supabase-reinicio-global.sql" desde SQL Editor. Las cuentas y contraseñas
se conservan: cada jugador podrá ingresar, pero comenzará sin personajes.
